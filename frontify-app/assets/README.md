# assets/

Complete worked examples for common Frontify App patterns. Each file contains
a description, full source code, and inline explanations. Reference these when
building or adapting an app — copy the relevant sections rather than using them
as scaffold starting points.

## Examples

| File | What it covers |
|------|---------------|
| [app-settings.md](app-settings.md) | Defining configurable settings with `defineSettings()` — inputs, dropdowns, checklists, toggles |
| [app-with-state.md](app-with-state.md) | Per-user state with `appUserState` — get, set, subscribe |
| [asset-viewer-social-media.md](asset-viewer-social-media.md) | Asset Viewer surface — multi-screen routing, JWT auth, third-party image upload (Bluesky) |
| [bulk-actions-app.md](bulk-actions-app.md) | Bulk Actions surface — operating on multiple selected assets via GraphQL |
| [secure-third-party-request.md](secure-third-party-request.md) | `executeSecureRequest` with `manifest.json` secrets and `%%SECRET_NAME%%` placeholders |
